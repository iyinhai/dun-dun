# 沌沌 · 认知炼金术 🧪

> 把记忆、技能、案例作为**元素**，通过化学反应合成**晶体**；晶体被使用验证后升级为**晶核**，晶核与晶核可以**合并进阶**。
> 萃取是还原（把精华拿出来），炼金是化合（两个东西反应生成第三种新东西）。

**名字来源**：混沌学园「第一性原理」+ 道德经「沌沌兮如婴儿之未孩」——万物未分化的可能性态。

**原理**：第一性原理 × 熊彼特组合创新——创新 = 已有元素的重新组合。

## 这是什么

一个 [Hermes Agent](https://github.com/NousResearch/hermes-agent) skill。装上后，你的 AI 助手获得「认知炼金」能力：

```
你说：把「服务打分行」和「北极星看板」炼一下
沌沌：备料 → 选反应式 → 加压（场景+第一性追问）→ 出晶体 → 回炉入本体
```

## 四种反应式

| 反应 | 配方 | 例子 |
|---|---|---|
| ⚗️ 嫁接 | A骨架 × B血肉 | 赫力昂诊断框架 × 同济业务 = 同济诊断 |
| 🧪 置换 | A场合 × B打法 | 冰希黎大赛打法 × 阿芙牙膏 = 合规AI化 |
| ⚛️ 聚合 | A + B → 新物种 | 特工周报玩法 × 能力模型 = 成长质询系统 |
| 🌀 裂变 | A拆隐藏维度反哺B | 「数据打通」拆出锚点五步法 |

## 三级进化（融装备的感觉）

```
元素（一条记忆/技能/案例）
  ↓ 反应
晶体 Crystal（初产，置信度≤60%，使用计数0/3）
  ↓ 被实际使用 ≥3 次
晶核 Core Crystal（有资格参与合并）
  ↓ 双晶核合并
新晶核（继承双方结构，血统可追溯）
```

**合并门槛**：只有晶核能合；两颗晶体「本质一句话」矛盾的不能合（只能并列）——防止废料堆山和强行缝合。

## 安装（Hermes 用户）

```bash
# 复制 SKILL.md 到你的 skills 目录
mkdir -p ~/.hermes/skills/dundun
curl -sL https://raw.githubusercontent.com/iyinhai/dun-dun/main/SKILL.md \
  -o ~/.hermes/skills/dundun/SKILL.md
```

然后对你的 agent 说一句：**「沌沌，把 X 和 Y 炼一下」**。

## 分享协议（内建）

- 炼金的是**炉子**（方法论），晶体长在各自主人的元素库里
- 对方第一炉必须自己出题——晶体必须长在自己的场景里
- 进阶：双方各拿 1 颗**晶核**交换当"外来元素"，首次使用置信度 -20%（水土不服折扣）
- 客户案例脱敏；用别人的晶核合并必须写血统

## 纪律（防自嗨内建）

- 无场景不产晶——说不出「解决谁的具体问题」的晶体不产出
- 备料阶段不评价；每炉候选 ≤3（防选择过载）
- 置信度诚实：初产 ≤60%，用一次涨一次
- 连续 3 次没被使用的晶体自动降级为「库存」，季度清理
